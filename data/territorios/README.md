# Territorialização pública de Lagoa de Itaenga

O CSV contém os 14 bairros urbanos e 9 territórios rurais explicitamente listados no diagnóstico municipal da pessoa idosa. Ele é uma camada territorial pública inicial para o VIGIA+.

Este arquivo não contém a atribuição operacional de ACE, microáreas, setores ou quarteirões. Essa informação deve ser solicitada à Secretaria Municipal de Saúde/SisPNCD/SisLOC pelo E-SIC.

Código IBGE: `2608503`.
