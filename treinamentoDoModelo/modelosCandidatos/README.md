# Candidatos preservados

Esta pasta recebe cópias dos artefatos que venceram baselines de contagem ou atingiram o piso de precisão para ocorrência na validação temporal. Execute:

```sh
treinamentoDoModelo/.venv/bin/python treinamentoDoModelo/executar.py arquivar
```

Os binários são ignorados pelo Git. Um candidato preservado ainda é um artefato de pesquisa: não representa aprovação epidemiológica ou modelo de produção.
